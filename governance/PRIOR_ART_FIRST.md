# PRIOR ART FIRST

Before bespoke design or build work is approved:

1. Define the exact endpoint and PASS evidence.
2. Search broadly for existing products, open-source projects, implementations and workflows that already solve it.
3. Compare the strongest candidates against current plans, permissions, €0 constraints, capabilities, owner involvement, allowance cost and verification path.
4. Do not stop at the first familiar candidate.
5. Do not begin bespoke implementation until prior art has been checked and the residual gap is explicit.
6. Build only the verified residual gap.

Canonical proof case: Icarus.
