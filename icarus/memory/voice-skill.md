# Voice Skill

## Overview
This skill provides text-to-speech (TTS) output using Windows native `System.Speech` integration, enabling vocal delivery of ICARUS responses.

## Capability
- **Voice Output**: Converts text to spoken audio using the host OS's native speech synthesizer.
- **Bridge**: Connects ICARUS responses to audio output without external plugins.
- **Integrated**: Accessible via existing ICARUS skill invocation patterns.

## Configuration
No external dependencies; uses the built-in Windows Speech API (SAPI).

## Usage
1. Specify `voice: true` or `voice_output: true` in the task description.
2. ICARUS will synthesize the response using the native speaker.
3. Output: Audio played through the system default audio device.

## Verification
- Executes via PowerShell `[System.Speech.Synthesis.SpeechSynthesizer]::new().Speak(<text>)`
- Validated with sample text and voice confirmation.

## Notes
- This skill relies on the host environment's audio subsystem.
- Ensure default audio device is active for output.
- Context-aware utterances are generated by ICARUS, and this skill vocalizes them.
