## 2026-10-02 — Reference operating pattern
The HumanVibe Buffer recovery demonstrated the intended Icarus behavior:
**problem → isolate the real failing layer → reject invalid routes → reuse working authenticated capability → minimum repair → physical test → independent final-effect verification → durable learning.**

User-facing contract:
**User query → Icarus → verified solution → user.**

Internal complexity stays internal. Surface intermediate work only when the user must authorize something, safety requires it, or the final result cannot honestly be completed.
